### 1. Student Marks Calculator

**Status:** Completed

A Flask web application that collects student details and subject-wise marks, then calculates and displays the results.

**Features implemented:**

- Collects student information and the number of subjects.
- Dynamically generates subject-entry fields.
- Accepts subject names, marks obtained, and maximum marks.
- Displays a subject-wise marks table.
- Calculates total marks and percentage.
- Includes a marks scale and grading system.
